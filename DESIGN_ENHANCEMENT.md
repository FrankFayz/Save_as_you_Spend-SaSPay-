## 🎨 Design System Applied

### **Color Palette**
```
Primary Green:     #22c55e (Main action, success states)
Darker Green:      #16a34a (Hover, active states)
Light Green:       #d1fae5(Text accents)
Mint Green:        #6ee7b7 (Labels, hints)
Emerald:           #10b981 (Confirmations)
Light Mint:        #a7f3d0 (Secondary text)
Dark Background:   #0f172a (Primary background)
```

### **Design Principles**
- **Glassmorphism**: Blur effects + transparency
- **Depth**: Inset shadows + drop shadows
- **Gradients**: 135° angle for modern feel
- **Typography**: Bold weights (700-950) for hierarchy
- **Spacing**: Generous padding (18-32px) for breathing room
- **Radius**: 14-24px for modern rounded corners
- **Transitions**: 0.2s cubic-bezier for smooth motion

- Buttons: 14-15px, weight 800

### **Shadows**
```css
/* Light shadow (subtle elements) */
0 4px 12px rgba(34, 197, 94, 0.1)

/* Medium shadow (cards) */
0 8px 32px rgba(34, 197, 94, 0.1)

/* Heavy shadow (modals) */
0 25px 50px rgba(0, 0, 0, 0.5)

/* Inset shadow (depth) */
inset 0 1px 0 rgba(255, 255, 255, 0.1)
```
